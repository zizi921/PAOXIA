## 数据与权限

微信原生云调用自动识别当前账号，不要求手机号、头像或昵称。云函数 `paoxiaSync` 仅接受平台注入的匹配 APPID 和 OPENID，忽略客户端提供的身份。`paoxia_runs` 集合设为 ADMINONLY，客户端无法直接读写。每条文档由账号与记录 ID 的 SHA-256 定位，包含记录、版本、幂等操作 ID 和删除标记。文字与可编辑矢量画作随记录保存，不依赖临时文件。

本机 `paoxia.syncState` 将记录与待传操作作为单个 Storage 值写入，保存成功意味着本机可靠落盘；只有服务器确认后显示已同步。旧 `paoxia.completedRuns` 首次绑定微信身份时迁移。不同账号缓存隔离，切换账号不继承计时和草稿。

云端使用版本条件更新防止覆盖：并发编辑保留本机修改为新记录，云端版本也保留；删除保留无正文的标记以同步至其他设备。清空删除当前已加载的记录，联网后传播。同步失败保留待传队列，重新进入、网络恢复或点击状态文字重试。退出或清理缓存前应确认已同步。

已保存的跑步、文字和画作同步；计时中的跑步、未完成草稿、语言偏好仍留在本机。没有手机号码注册或独立密码。
