# PAOXIA UI 演示

在微信开发者工具中导入仓库根目录。`project.config.json` 保留现有 AppID 配置；真机预览需当前微信账号拥有该 AppID 的开发权限。

- GO → 跑步页；Days Out. → 跑步记录页。
- 首页提供灰色 `EN / 中文` 切换；选择保存在本机，四个页面的界面文案、日期、时长和历史记录展示会使用所选语言。
- 跑步页实时显示时长；Pause / Resume 暂停和继续计时。距离在跑后记录页手动填写。
- Done → 跑后记录页；Save → 跑步记录页；Go again → 首页。跑动中或暂停时都可以直接结束。
- Save 将本次时长、手动填写的距离、天气、心情、多个见闻和备注追加到小程序本机 Storage，关闭重开后仍可查看，不上传。
- 跑步记录页保留 Year / Month / Day 三种视图，统计来自本机已保存的真实记录；无记录时显示空状态。Month 列出每条记录，点击可查看对应 Day 详情，同一天的多次跑步也可分别查看；Edit 可修改记录，或经二次确认后永久删除。
- 点击 GO 后开始计时；跑步时长会带到跑后记录页展示。
- 小程序不申请定位权限。锁屏或微信进入后台后，跑步时长依据本机时间点继续计算；距离在跑完后由用户填写。
- 未完成跑步保存在本机，重开后首页显示“继续这次”，恢复时长和暂停状态；Done 结束后清除。表单草稿仍不持久化；不做 CloudBase 连接、账号识别或跨设备同步。

页面文字、颜色、按钮和布局均在 WXML/WXSS 中编辑。人物是独立 PNG 素材。系统状态栏和胶囊由微信提供。

本地行为检查：`node scripts/check-ui.cjs`。微信环境验收：连续保存两次跑步（可在同一天，至少一次留空距离、心情和备注），从 Month 分别打开两条详情，核对 Year / Month 次数和总时长；关闭并重新打开小程序，通过首页 Days Out. 确认两条记录仍在。不要清除小程序缓存或 Storage。

切片 4 微信环境验收：计时中关闭重开，点击“继续这次”确认时长连续；暂停后关闭重开，确认仍暂停且等待时间不计入时长；恢复跑步再暂停一次，确认累计时长正确；Done 并 Save 后回首页确认显示 GO。存在未完成跑步时，首页主按钮应继续原跑步，不新建覆盖。
