# PAOXIA UI 演示

在微信开发者工具中导入仓库根目录。`project.config.json` 保留现有 AppID 配置；真机预览需当前微信账号拥有该 AppID 的开发权限。

- GO → 跑步页。
- Pause / Resume → 仅切换展示状态。
- I'm back → 跑后记录页；Save → 首页。
- 跑后记录页的心情、见闻、距离和备注仅保留在页面内，不会保存或上传。
- 00:08:21 为固定演示值，不运行真实计时，不保存数据，不连接 CloudBase。

页面文字、颜色、按钮和布局均在 WXML/WXSS 中编辑。人物是独立 PNG 素材。系统状态栏和胶囊由微信提供。
