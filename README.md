# PAOXIA UI 演示

在微信开发者工具中导入仓库根目录。`project.config.json` 保留现有 AppID 配置；真机预览需当前微信账号拥有该 AppID 的开发权限。

- GO → 跑步页；Days Out. → 跑步记录页。
- 首页提供灰色 `EN / 中文` 切换；选择保存在本机，四个页面的界面文案、日期、时长和历史记录展示会使用所选语言。
- 四个页面均可通过微信右上角「…」发送给朋友；首页还支持分享到朋友圈。分享文案跟随当前界面语言，使用固定人物插画，打开后进入首页，不携带本机记录、备注、草稿或计时参数。
- 跑步页实时显示时长及 GPS 公里数；Pause / Resume 暂停和继续计时、定位。距离自动回填到跑后记录页，仍可手动修改。
- Done → 跑后记录页；Save → 跑步记录页；Go again → 首页。跑动中或暂停时都可以直接结束。
- Save 进入 Note；点击 Done 后将本次时长、距离、天气、心情、见闻、文字与画作保存到本机队列，并按微信身份同步云端。首页和历史页显示实际同步状态；同步成功后同一微信账号换手机可恢复。
- 跑后表单点击 Save 打开 Note，Text 输入文字，Draw 手绘，支持画笔、橡皮、撤销及自选颜色；Back 返回表单，Done 保存并进入详情。文字与画作可以同时保留，并通过 Edit 继续修改。
- 跑步记录页保留 Year / Month / Day 三种视图，统计来自本机缓存及云端同步的真实记录；无记录时显示空状态。Month 列出每条记录，点击可查看对应 Day 详情，同一天的多次跑步也可分别查看；Edit 可修改记录，或经二次确认后永久删除。
- 点击 GO 后开始计时；跑步时长会带到跑后记录页展示。
- 小程序申请跑步期间的前后台定位权限；需微信后台开通接口及完成隐私声明，见 `docs/gps-distance.md`。锁屏或微信进入后台后使用后台位置回调累计距离；权限不可用时保留计时及手填距离。进程被终止或定位中断的缺失路段无法补算，页面会提示核对。经纬度仅在内存参与计算，本机草稿保存相对位移；完成记录可同步不带地图与地理坐标的路线轮廓，并在 Day 详情显示。
- 未完成跑步保存在本机，重开后首页显示“继续这次”，恢复时长和暂停状态；Done 后转为一份本机跑后表单草稿，填写内容会持续保存，可继续同一次跑步；保存成功或主动放弃后清除。已保存记录按微信账号跨设备同步；正在计时、跑后草稿和语言选择仍保存在当前设备。

页面文字、颜色、按钮和布局均在 WXML/WXSS 中编辑。人物是独立 PNG 素材。系统状态栏和胶囊由微信提供。

分享真机验收：分别从首页、跑步页、跑后表单和历史详情打开「…」发送给朋友，确认卡片为固定插画，接收方打开后进入首页；首页切换 EN / 中文后核对分享标题；从首页分享到朋友圈并打开。分享返回后确认原计时或暂停状态、表单草稿仍正常。朋友圈仅在首页开放，避免接收方直接进入依赖本机数据的页面。菜单显示与实际发送需在微信真机验证。

本地行为检查：`node scripts/check-ui.cjs`、`node scripts/check-sync.cjs`、`node scripts/check-location.cjs` 和 `node scripts/check-route.cjs`。云端配置与验收见 `docs/cloud-sync.md`。微信环境验收：连续保存两次跑步（可在同一天，至少一次留空距离、心情和备注），从 Month 分别打开两条详情，核对 Year / Month 次数和总时长；关闭并重新打开小程序，通过首页 Days Out. 确认两条记录仍在。不要清除小程序缓存或 Storage。

切片 4 微信环境验收：计时中关闭重开，点击“继续这次”确认时长连续；暂停后关闭重开，确认仍暂停且等待时间不计入时长；恢复跑步再暂停一次，确认累计时长正确；Done 并 Save 后回首页确认显示 GO。存在未完成跑步时，首页主按钮应继续原跑步，不新建覆盖。
