# PAOXIA UI 演示

在微信开发者工具中导入仓库根目录。`project.config.json` 保留现有 AppID 配置；真机预览需当前微信账号拥有该 AppID 的开发权限。

- GO → 跑步页；Days Out. → 跑步记录页。
- Pause / Resume → 暂停和继续计时，暂停时间不计入跑步时长。
- Done → 跑后记录页；Save → 跑步记录页；Go again → 首页。跑动中或暂停时都可以直接结束。
- Save 将本次时长、天气、心情、多个见闻、距离和备注追加到小程序本机 Storage，关闭重开后仍可查看，不上传。
- 跑步记录页保留 Year / Month / Day 三种视图，统计来自本机已保存的真实记录；无记录时显示空状态。Month 列出每条记录，点击可查看对应 Day 详情，同一天的多次跑步也可分别查看。
- 点击 GO 后开始计时；跑步时长会带到跑后记录页展示。
- 未完成跑步和表单草稿不持久化；不做 CloudBase 连接、账号识别或跨设备同步。

页面文字、颜色、按钮和布局均在 WXML/WXSS 中编辑。人物是独立 PNG 素材。系统状态栏和胶囊由微信提供。

本地行为检查：`node scripts/check-ui.cjs`。微信环境验收：连续保存两次跑步（可在同一天，至少一次留空距离、心情和备注），从 Month 分别打开两条详情，核对 Year / Month 次数和总时长；关闭并重新打开小程序，通过首页 Days Out. 确认两条记录仍在。不要清除小程序缓存或 Storage。
